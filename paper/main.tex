\begin{abstract}
We study an impartial take-away game where consecutive removals must differ by more than a fixed distance. We prove an interval classification of losing full-state rows, eventual periodicity for fixed parameters, and a universal row recurrence with a closed-form run hierarchy. Exact finite-window certificates and induction establish twelve parameter intervals through group $j=13$, covering $10323$ pairs. Adjacent counterexamples bound each contiguous interval. The new second-position interval is $15018\le k\le20025$ at $A=21846$, with upper-boundary failure at $n=83746$. A parameter-uniform proof and global exclusion of additional intervals remain \emph{Open}.
\end{abstract}

\section{Research context, question, and method}
A move of size $r$ after a previous removal $s$ is legal only if $|r-s|>m$. This history dependence makes the state $(n,s)$ essential. We ask which starting heap sizes are losing, why their binary sequence becomes periodic, and whether explicit periods and residues depend affinely on the maximum move $k$. Standard Sprague--Grundy theory motivates the P/N recurrence \cite{sprague1935,grundy1939,winningways2001}. Prior work on repetition-free subtraction games provides an adjacent literature thread rather than a borrowed solution of the present $m=1$ game \cite{gurvich2012}.

We followed this process: (i) model the full state and derive an exact Boolean recurrence; (ii) independently cross-check it against naive P/N and direct Sprague--Grundy solvers; (iii) identify candidate affine residue patterns by exploratory scan; (iv) prove a finite-window implication by induction; (v) verify exact base windows and the necessary finite starting prefix for each fixed $k$; (vi) classify exceptional parameter boundaries, and (vii) identify conjectural claims explicitly as \emph{Open}. The source code and data are under \texttt{src/} and \texttt{data/certificates/}; per-theorem verification scripts and method notes are organized under \texttt{methodology/} and summarized in Section~\ref{sec:methodology}.

\section{Research conclusion and limitations}
The universal row recurrence and infinite run hierarchy have symbolic proofs. Twelve finite parameter intervals are established by certificates and induction, with adjacent counterexamples and separately certified collapse cases. The $j=13$ extension adds $7740$ pairs to the earlier $2583$. These results do not prove a parameter-uniform regime theorem or exclude disconnected valid intervals. The upper-endpoint formula, the all-group genuine/non-genuine conjecture, and a broader originality review remain open.
