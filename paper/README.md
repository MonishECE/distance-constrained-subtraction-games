# Manuscripts

`main.tex` integrates the game definition, Theorems A/B/C, evidence tables, limitations and references. `theorem_A/main.tex`, `theorem_B/main.tex` and `theorem_C/main.tex` include their prerequisites and can be compiled separately from their own folders. Shared formatting and references are in `shared/`.

Compile twice with pdfLaTeX to resolve references. Single-file equivalents are in `../overleaf/`. The LaTeX sources are authoritative; compile them to produce PDFs.
